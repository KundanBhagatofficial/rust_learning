Comments:
Rust support multiple comment types:
1. Line Comment: '//',  Starts with // and continues to the end of the line
2. Block Comments: '/* ... */', enclosed between /* ... */ and can span across multiple lines

Rust also support Documentation Comments, which are parsed into HTML library.
1. /// : Generate docs for the items that follows it
2. //! : Generates docs for the enclosing item (used at top of a file or module)
